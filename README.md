# 🏫 Landing Page SENAI — CSS Grid Layout

Este repositório contém o projeto de uma **Landing Page** responsiva desenvolvida para o **SENAI**, focada na prática e aplicação de **CSS Grid Layout** para estruturação e alinhamento do conteúdo web.

---

## 📌 Sobre o Projeto

O objetivo deste projeto é recriar/refatorar uma landing page institucional para o SENAI, utilizando modernos conceitos de layout bidimensional fornecidos pelo **CSS Grid**, além de garantir organização de estilos e reutilização de componentes gráficos.

---

## 📁 Estrutura de Arquivos

| Arquivo / Pasta | Descrição |
| :--- | :--- |
| `Códigos/` | Pasta de apoio contendo versões anteriores ou trechos de código do projeto. |
| `assets/` | Recursos visuais, ícones e imagens utilizados no layout da página. |
| `css/` | Folhas de estilo do projeto contendo as regras de grid, tipografia e responsividade. |
| `index.html` | Arquivo principal com a estrutura semântica HTML5 do projeto. |
| `.gitattributes` | Arquivo de configuração do Git. |

---

## 🚀 Tecnologias e Conceitos Utilizados

- **HTML5** (Estruturação semântica)
- **CSS3**
  - **CSS Grid Layout** (`grid-template-columns`, `grid-template-rows`, `gap`, etc.)
  - **Design Responsivo** (Media Queries)
  - **Flexbox** (Alinhamento complementar)
